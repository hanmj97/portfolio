# 한민재 | Technical Portfolio — Minimal White + Dashboard

## 확인 방법
`index.html` 파일을 Chrome / Edge에서 열어주세요. 별도 설치 불필요.

## 배포
GitHub에 새 공개 저장소를 만들고 이 폴더의 `index.html`, `style.css`, `script.js`를 루트에 올립니다. Settings → Pages → Deploy from a branch → `main` / `(root)` 선택 후 공개 주소 확인.

## 구성
- 미니멀 화이트 기반 반응형 홈페이지
- 인터랙티브 프로젝트 필터, 모바일 메뉴, DataOps 데이터 흐름 도식
- 3종 Google Drive PDF 문서 + Notion 이력서 이동 링크
- 블랙잭 GitHub 저장소 및 데모 링크

## 주의
- Google Drive 파일 3개의 링크는 제공받은 주소를 그대로 사용했습니다. 파일 내용과 외부 공개 권한은 직접 검증하지 않았으므로 링크를 시크릿 창에서 확인해 주세요.
- 경력 정보는 2026-10-07 기준 Notion 이력서 및 기존에 공유된 경력 사례를 기반으로 작성했습니다.
- DataOps는 사용자의 요청에 따라 완료 프로젝트로 표시하며, 경험 수치는 Notion 기재 기간을 근거로 개략적으로 표시했습니다.
- 이메일이 웹페이지에 공개됩니다. 필요시 `index.html`에서 수정하세요.
- Google Fonts를 사용하므로 온라인 환경에서 글꼴이 더 잘 표시됩니다. 오프라인 환경에서는 시스템 글꼴로 대체됩니다.


## 색상 테마
